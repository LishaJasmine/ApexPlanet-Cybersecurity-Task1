
# ApexPlanet Cybersecurity Internship — Task 1

## Foundation and Environment Setup

### Overview
This repository documents the practical activities completed for Task 1 of the ApexPlanet Software Pvt. Ltd. Cybersecurity and Ethical Hacking Internship.

### Objectives
- Set up a controlled cybersecurity practice environment.
- Practise basic Linux file and directory operations.
- Understand and verify Linux file permissions.
- Inspect network interfaces and routing information.
- Perform sample file encryption and decryption using OpenSSL.
- Capture and inspect network packets using Wireshark.
- Verify the availability of commonly used cybersecurity tools.
- Configure and test connectivity between Kali Linux and Metasploitable2.

### Lab Environment

|       Component          |       Description        |
|--------------------------|--------------------------|
| Host operating system    | Windows                  |
| Virtualization software  | Oracle VirtualBox        |
| Analysis virtual machine | Kali Linux               |
| Target virtual machine   | Metasploitable2          |
| Virtual network          | Host-Only                |
| Packet analysis tool     | Wireshark                |
| Cryptography tool        | OpenSSL                  |
| Other tools              | Nmap, Burp Suite, Netcat |

### Practical Activities
1. Virtual lab and Host-Only network configuration.
2. Linux file and directory management.
3. File permission management using `chmod` and `ls -l`.
4. Network inspection using `ip -br addr` and `ip route`.
5. Sample file encryption and decryption using OpenSSL.
6. Network traffic capture using Wireshark.
7. ICMP filtering and packet inspection.
8. Saving packet captures in PCAPNG format.
9. Checking cybersecurity tools in Kali Linux.
10. Inspecting the Metasploitable2 network configuration.
11. Testing connectivity between Kali Linux and Metasploitable2.

###Tools Used
- Kali Linux
- Oracle VirtualBox
- Metasploitable2
- Wireshark
- OpenSSL
- Nmap
- Burp Suite
- Netcat

### Learning Outcomes
This task provided practical experience with Linux commands, file permissions, network configuration, basic cryptography, packet analysis, and cybersecurity lab setup.

### Lab Safety
All testing was performed in a controlled virtual lab. Metasploitable2 was used as an intentionally vulnerable target on a Host-Only network.
